# Andre Miranda – CS 499 Computer Science Capstone ePortfolio

This repository hosts my CS 499 ePortfolio, demonstrating mastery across three core areas of computer science:

- **Software Engineering & Design**
- **Algorithms & Data Structures**
- **Databases**

The ePortfolio is published using GitHub Pages and includes original artifacts, enhanced artifacts, narratives, a full code review, and a professional self‑assessment.

---

## 📌 Project Overview

The primary artifact enhanced throughout the capstone is the **Grazioso Salvare Rescue Dashboard**, originally developed in CS 340. The enhanced version includes:

### ✔ Software Engineering Enhancements
- Custom exception hierarchy  
- Structured logging  
- Environment‑based credential management  
- Schema validation  
- Index creation  
- Modular refactoring  

### ✔ Algorithms & Data Structures Enhancements
- Rescue Suitability Scoring Engine  
- Weighted scoring model  
- Breed normalization with caching  
- Compiled regex for performance  
- Ranking and sorting algorithms  

### ✔ Database Enhancements
- MongoDB aggregation pipelines  
- Index optimization  
- Data cleaning and validation  
- Dashboard analytics (KPI tiles, histograms, grouped bar charts)
